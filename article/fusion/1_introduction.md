# 想做CTA量化，到底该从哪开始？一张完整路线图

做交易的人，大多经历过这样的夜晚：盯了一整晚螺纹钢，凌晨实在扛不住睡着了，第二天睁眼发现夜盘走出了教科书级别的突破行情。

也有反过来的版本：行情来了，人也在屏幕前，却因为犹豫多看了两根K线，最好的进场点已经过去了。

于是开始琢磨：能不能让程序替我盯盘、替我执行？

这就是CTA量化最朴素的起点。CTA是行业里对趋势波段类量化策略的习惯叫法，以期货品种为主要战场——把你的交易纪律写成明确的规则，交给机器一丝不苟地执行，仅此而已。

难的地方在于，从"想做"到"真的在实盘里跑起来"，中间隔着几道坎。这些年在VeighNa社区论坛里，我们回答过大量新手提问，卡住的位置出奇地集中，基本就是那么五个。

这篇文章把这条路完整画出来。它是本系列的开篇，只负责画地图，每道坎的细节都留给后面的文章展开。如果你正站在起点，希望读完后你至少清楚：接下来要过哪几关，每一关难在哪。

先把最重要的一句话放在前面：

**做量化的第一道坎不是编程，而是把"我感觉能赚钱"翻译成机器能执行的规则。**

## 第一道坎：把想法变成规则

"均线金叉就做多"——听起来已经很像一条规则了，机器却没法执行。用几分钟的K线算均线？金叉出现在盘中就进场，还是等收盘确认？进场之后什么时候离场？浮亏了扛多久？下一手还是下十手？

主观交易者靠盘感在临场补上这些空白，程序补不了，每一个细节都必须事先写死。

论坛里常见一种提问：策略想法说了三行字，就问"这个能不能做成程序化"。我们通常要反问七八个问题，才能把规则问完整——提问者往往这时才发现，自己的"策略"里有大量"看情况"的成分，而规则里容不下"看情况"。

多数人以为自己缺的是编程能力，真正动手后才发现卡住自己的是这一步。第2篇会给出一套把想法拆成规则的完整框架。

## 第二道坎：搞到能用的数据

有了规则，验证它需要历史数据，而CTA策略主要交易的期货品种，历史数据比股票麻烦得多。股票代码背后是一串连续的价格历史；期货合约几个月就到期退市，想回测三年，得把一串不同月份的合约接起来用，这就是所谓的"连续合约"。

接合约的规则五花八门：什么时候算主力切换、新旧合约之间的价差怎么处理，每家软件的做法都不一样。

所以"我下载的主力连续数据和文华对不上"这类问题，在论坛上十年没有断过，而它背后多数是拼接规则的差异，数据本身没有错。用错了连续合约类型，回测结果会在换月的日子凭空多出一笔盈亏，整个结论跟着失真。

第3篇专门讲数据，重点就是连续合约的门道。

## 第三道坎：把规则变成代码

这道坎正在肉眼可见地变矮。三年前，你需要先学Python语法、再学量化框架，才能写出第一个策略；今天，AI已经可以根据一段文字描述直接生成完整的策略代码。

门槛降低的同时带来一个新问题：AI替你写的代码，你得看得懂——实盘时按这份代码下单的，是你自己的钱。

好消息是，看懂一份策略代码比写出它容易得多。CTA策略代码有非常固定的结构，知道每个部分管什么，就能按图索骥核对它和你的想法是否一致。第4篇教你读懂策略代码，不需要任何编程基础。

## 第四道坎：证明它真的有效

回测收益翻倍，实盘三个月亏光利润——这几乎是量化新手的必经之路。

回测是会"骗人"的：代码里不小心用了未来的信息、忘了算手续费和滑点（下单价格与实际成交价格之间的偏差）、参数反复调整直到完美贴合历史行情，每一种都能造出漂亮的假象，而且造假的人往往是无意的。

我们把这道坎放在系列里着墨最多的位置，因为它最容易自欺：前三道坎过不去，你会明确地知道自己卡住了；这一道坎过不去，你会带着错误的信心走向实盘。第5、6、7三篇分别讲AI生成代码的审查方法、回测报告的正确读法，以及参数优化里的过拟合陷阱。

## 第五道坎：合规走进实盘

策略验证完毕，最后一步是把它合法合规地接入真实账户。自2025年程序化交易监管新规落地后，个人开展程序化交易需要向期货公司报备、申请相应权限；如果用的是自己搭建的交易系统，还需要完成与期货公司柜台的接入测试流程。

这一步没有任何技术含量，却让相当一部分人在最后一公里停了下来——流程不熟、材料不知道怎么准备、测试环节来回折腾。第8篇会把整个流程讲清楚。

## 两条上手路径

看完五道坎，再说工具。上手CTA量化，目前主要有两条路：自己搭建开源工具链，或者使用期货公司提供的标准化平台。两条路的差别可以用一张表说清：

| | 自建开源工具链 | 期货公司标准化平台 |
|---|---|---|
| 代表 | VeighNa 开源版 | VeighNa Fusion |
| 环境搭建 | 自行安装Python、配置数据库、对接数据源和交易接口 | 无需搭建，数据、回测与AI策略开发工具已内置 |
| 获取方式 | 自行下载部署 | 在合作期货公司开户并申请开通权限 |
| 费用 | 软件免费，数据服务等自行解决 | 无需额外付费 |
| 自由度 | 最高，每个环节自主掌控 | 标准化功能，开箱即用 |
| 适合人群 | 有开发能力、把量化当长期事业的用户 | 想先完整走一遍流程、再决定投入的交易者 |

交代一下两者的关系：VeighNa是我们维护了十年以上的开源量化框架，Fusion则是在它的基础上，为期货公司渠道打造的标准化版本。

两条路并不冲突。策略代码用的是同一套标准——VeighNa的CTA策略模板，从平台起步、之后转向自建，或者反过来，都不需要推倒重来。

本系列后续的操作演示将基于Fusion完成，但每篇的知识本身与工具无关，用任何平台的读者都可以对照阅读。
