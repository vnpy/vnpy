在[这里](https://github.com/vnpy/vnpy/releases)下载Release发布版本，解压后运行以下命令安装：

**Windows**

```
install.bat
```

**Ubuntu**

```
bash install.sh
```

**Macos**

```
bash install_osx.sh
```

## 使用指南

1. 在[SimNow](http://www.simnow.com.cn/)注册CTP仿真账号，并在[该页面](http://www.simnow.com.cn/product.action)获取经纪商代码以及交易行情服务器地址。

2. 在[VeighNa社区论坛](https://www.vnpy.com/forum/)注册获得VeighNa Station账号密码（论坛账号密码即是）

3. 启动VeighNa Station（安装VeighNa Studio后会在桌面自动创建快捷方式），输入上一步的账号密码登录

4. 点击底部的**VeighNa Trader**按钮，开始你的交易！！！

注意：

* 在VeighNa Trader的运行过程中请勿关闭VeighNa Station（会自动退出）

## 脚本运行

除了基于VeighNa Station的图形化启动方式外，也可以在任意目录下创建run.py，写入以下示例代码：

```Python
from vnpy.event import EventEngine
from vnpy.trader.engine import MainEngine
from vnpy.trader.ui import MainWindow, create_qapp

from vnpy_ctp import CtpGateway
from vnpy_ctastrategy import CtaStrategyApp
from vnpy_ctabacktester import CtaBacktesterApp


def main():
    """Start VeighNa Trader"""
    qapp = create_qapp()

    event_engine = EventEngine()
    main_engine = MainEngine(event_engine)
    
    main_engine.add_gateway(CtpGateway)
    main_engine.add_app(CtaStrategyApp)
    main_engine.add_app(CtaBacktesterApp)

    main_window = MainWindow(main_engine, event_engine)
    main_window.showMaximized()

    qapp.exec()


if __name__ == "__main__":
    main()
```بعد فتح CMD في هذا الدليل (اضغط مع الاستمرار على Shift-> انقر بزر الماوس الأيمن-> افتح نافذة الأوامر/PowerShell هنا)، قم بتشغيل الأمر التالي لبدء VeighNa Trader:

بايثون run.py

## رمز المساهمة

يستخدم VeighNa Github لاستضافة شفرة المصدر الخاصة به. إذا كنت ترغب في المساهمة في التعليمات البرمجية، فيرجى استخدام عملية العلاقات العامة (طلب السحب) الخاصة ب github:

1. [إنشاء مشكلة] (https://github.com/vnpy/vnpy/issues/new) - بالنسبة للتغييرات الأكبر (مثل الوظائف الجديدة، وإعادة الإعمار على نطاق واسع، وما إلى ذلك)، يوصى بفتح مشكلة لمناقشتها أولا، وإرسال العلاقات العامة مباشرة لتحسينات أصغر (مثل تحسين المستندات، وإصلاح الأخطاء، وما إلى ذلك).

2. شوكة [VeighNa](https://github.com/vnpy/vnpy) - انقر فوق الزر **Fork** في الزاوية اليمنى العليا

3. استنساخ الشوكة الخاصة بك: ```git clone https://github.com/$userid/vnpy.git```

* إذا كانت شوكة قديمة، فأنت بحاجة إلى المزامنة يدويا: [طريقة المزامنة] (https://help.github.com/articles/syncing-a-fork/)

4. قم بإنشاء فرع الميزة الخاص بك من **dev**: ```git checkout -b $my_feature_branch dev```

خمسة. قم بالتعديل على $my_feature_branch وقم بتعديل الدفع إلى شوكة الخاص بك

6. قم بإنشاء [طلب سحب] من فرع $my_feature_branch من شوكتك إلى فرع **dev** للمشروع الرئيسي - [هنا] (https://github.com/vnpy/vnpy/compare؟ توسيع = 1) انقر فوق **مقارنة عبر الشوك **، وحدد الشوكة والفرع المطلوبين لإنشاء العلاقات العامة

7. في انتظار المراجعة، تحتاج إلى الاستمرار في التحسين، أو الاندماج!

عند إرسال التعليمات البرمجية، يرجى اتباع القواعد التالية لتحسين جودة التعليمات البرمجية:

* استخدم [ruff] (https://github.com/astral-sh/ruff) للتحقق من نمط التعليمات البرمجية الخاص بك للتأكد من عدم وجود خطأ أو تحذير. قم بتشغيل فحص "ruff" في الدليل الجذر للمشروع. لا بأس.

* استخدم [mypy] (https://github.com/python/mypy) للتحقق من النوع الثابت للتأكد من صحة التعليق التوضيحي للنوع. فقط قم بتشغيل ```mypy vnpy``` في الدليل الجذر للمشروع.
